# Tank-o-box — GitHub Pages

Содержимое этой папки — готовый статический сайт. Загрузите ВСЕ файлы и папки
в корень репозитория, включая .nojekyll, assets и vendor. index.html должен
лежать в корне, а не внутри дополнительной папки github-pages или dist.

GitHub → Settings → Pages → Deploy from a branch → main → / (root) → Save.
Игра работает как по адресу https://USER.github.io/REPO/, так и на своём домене.
Не загружайте сам ZIP вместо распакованного содержимого. Сборка не требует Node.js
на хостинге. Для локальной игры используйте HTTP-сервер, а не file://.

Музыка включается после первого нажатия мыши или клавиши (правило браузера).
Настройки и рекорды сохраняются в браузере. Панель отладки: ?debug=1.
Главная страница — index.html, страница Tank-o-Box — game.html. Кнопка «Играть»
открывает play.html; игровой движок
и ресурсы не загружаются, пока посетитель не нажмёт эту кнопку.
При обновлении замените все файлы сборки, дождитесь публикации Pages и один раз
обновите страницу через Ctrl+F5. Версии ресурсов в URL защищают от старого кеша.

Это незавершённый перенос Tank-o-box из локальной установки пользователя.
Оригинальные материалы принадлежат их авторам. Перенос выполнен с помощью Codex.
Three.js и libopenmpt: лицензии находятся в vendor.
